# Hauk Go backend

A self-contained alternative to the PHP backend. It implements the same API,
so the Hauk Android app and the web frontend work unchanged, and it ships as a
single binary that includes the web frontend. No web server, PHP or memcached
is needed.

## Differences from the PHP backend

- All sessions and shares are kept in memory and are lost when the server
  restarts. Running multiple instances behind a load balancer is not supported.
- Configuration is a YAML file instead of `config.php`; see
  [config-sample.yaml](config-sample.yaml). Option names are the same as in
  `config.php`, and every option can be overridden by an environment variable
  such as `HAUK_PUBLIC_URL`.
- Supported authentication methods are `PASSWORD` and `HTPASSWD`. LDAP is not
  supported. Password hashes may be bcrypt, MD5-crypt (`$1$`, `$apr1$`),
  SHA-crypt (`$5$`, `$6$`) or SHA-1 (`{SHA}`).
- Share links also work without the question mark: `https://example.com/1234-ABCD`
  redirects to `https://example.com/?1234-ABCD`. Links generated by the server
  keep the question mark.
- Incremental map updates work for end-to-end encrypted shares. The PHP backend
  compares encrypted timestamps as numbers and therefore returns no new points
  for them after the initial page load.
- The Hauk logo on the map can be hidden with `hide_logo: true`
  (`HAUK_HIDE_LOGO=true`), and the map buttons that show the viewer's own
  location and the list of users with `hide_locate_button` and
  `hide_user_list_button`.
- Users of the Android app can share the live streams of their RemoteCam
  cameras, which are shown on the map.

## Building

Go 1.26 or newer is required. From the repository root:

```sh
go build -o hauk ./backend-go
```

## Running

```sh
cp backend-go/config-sample.yaml /etc/hauk/config.yaml
# Set password_hash and public_url, then:
./hauk
```

The server listens on port 8080 by default (option `listen` or flag
`-listen`). Put it behind a reverse proxy that terminates TLS, and set
`public_url` to the public address with a trailing slash. The configuration
file can also be given with `-config` or `HAUK_CONFIG`.

Without a configuration file, the server can be configured entirely through
environment variables:

```sh
HAUK_PASSWORD_HASH="$(htpasswd -nBC 10 "" | tail -c +2)" \
HAUK_PUBLIC_URL=https://hauk.example.com/ \
./hauk
```

## Migrating from the PHP backend

`convert-config.py` converts an existing `config.php` to a `config.yaml`. It
only needs Python 3; PHP does not have to be installed.

```sh
backend-go/convert-config.py /etc/hauk/config.php -o /etc/hauk/config.yaml
```

Storage and LDAP options are omitted with a warning. The script refuses to
convert configurations that use LDAP authentication, which the Go backend does
not support.

## Docker

```sh
docker build -f backend-go/Dockerfile -t hauk-go .
docker run -p 8080:8080 -v /etc/hauk:/etc/hauk:ro hauk-go
```

## Tests

```sh
go test ./backend-go
```
